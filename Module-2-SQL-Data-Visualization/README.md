# Module 2: SQL Fundamentals & Data Visualization

## Overview

This module focuses on developing SQL skills for data extraction, transformation, aggregation, and analysis, as well as presenting insights through data visualization.

## Topics Covered

- SQL fundamentals and filtering
- Aggregation and grouping
- UNION, JOIN, and Common Table Expressions (CTEs)
- Marketing campaign performance metrics
- String functions and handling NULL values
- Date and window functions
- Dashboard development with Google Looker Studio
- Google Analytics 4 (GA4) data analysis using BigQuery
