# Module 1: Google Sheets

## Overview
This module focuses on developing practical data analytics skills using Google Sheets. The projects cover product performance analysis and user engagement analysis using cohort-based metrics.

## Projects

### 1. Product Metrics Analysis
An analysis of product performance metrics to understand business results and support data-driven decision-making.

**Key focus areas:**
- Product performance metrics
- Data analysis using Google Sheets
- Business insights and interpretation

**Project repository:** [product-metrics-analysis](https://github.com/seymanursayit/product-metrics-analysis)

### 2. User Engagement Cohort Analysis
A cohort analysis project focused on understanding user engagement patterns over time and evaluating how user behavior changes across cohorts.

**Key focus areas:**
- Cohort analysis
- User engagement metrics
- Retention and behavioral trends
- Data-driven insights

**Project repository:** [user-engagement-cohort-analysis](https://github.com/seymanursayit/user-engagement-cohort-analysis)

## Skills Developed
- Data analysis using Google Sheets
- Product and user engagement metrics
- Cohort-based analysis
- Data interpretation and analytical thinking
- Communicating findings through structured analysis
